## WakeMyPC Docker based transmitter

- Built on Rust.
- Check out [WakeMyPC](https://wakemypc.com)

### What is WakeMyPC
- WakeMyPC is a SaaS service available for free that helps you wake up and shutdown your PC from anywhere on the internet.

## How to run
- Build docker container `docker compose build`
- Run the container `docker compose up`
